# AGENTS.md

This file provides guidance for AI agents working in this repository.

## Repository Overview

This is a static personal/academic portfolio website served via GitHub Pages. The site is built from structured content files by a custom Python compilation script — `index.html` is a **generated artifact** and should never be edited directly.

## Build System

### Running the build

```bash
python compile_page.py content/template.html
```

This reads all content source files, processes them, and **overwrites `index.html`** in place. Run this after every content change.

### Dependencies

Only one Python package is required:

```bash
pip install markdown
```

There is no `requirements.txt`. Python 3 is assumed.

## Content Format

Content files use standard Markdown **plus** custom extensions specific to this build system.

### Plain Markdown files

`presentation.md`, `tt_preamble.md`, and `service.md` are standard Markdown. They are passed directly through the `markdown` library and injected into the template.

### Structured block files

`papers.md`, `experience.md`, and `techtransfer.md` use typed triple-colon fence blocks:

```
:::paper
...content...
:::

:::job
...content...
:::

:::tech
...content...
:::
```

Each block becomes an `<article>` element in the output.

### Special tokens inside structured blocks

| Token | Syntax | Rendered as |
|-------|--------|-------------|
| Venue/conference tag | `[[[CVPR 2026]]]` | `<header>CVPR 2026</header>` |
| Project page link | `[[Project Page](https://...)]` | Globe icon link in article footer |
| Pre-print/PDF link | `[[Pre-print](https://...)]` | PDF icon link in article footer |

Images inside structured blocks automatically receive `class='float-left'` (150px left-float thumbnail layout).

### Example paper block

```markdown
:::paper
![](fig/example_teaser.png)
[[[NeurIPS 2024]]]
**Paper Title**

_Author One, **Author Two**, Author Three_

[[Pre-print](https://arxiv.org/abs/...)]
[[Project Page](https://example.com/project/)]
:::
```

## Template

`content/template.html` uses Python's `str.format()` style placeholders. Because of this, all literal curly braces in CSS must be doubled (`{{` / `}}`).

Named slots in the template:

| Placeholder | Source |
|-------------|--------|
| `{presentation}` | `content/presentation.md` |
| `{tt_preamble}` | `content/tt_preamble.md` |
| `{techtransfers_column1}` | Odd-indexed items from `content/techtransfer.md` |
| `{techtransfers_column2}` | Even-indexed items from `content/techtransfer.md` |
| `{papers}` | `content/papers.md` |
| `{service}` | `content/service.md` |
| `{experience}` | `content/experience.md` |

## Key Rules for Agents

1. **Never edit `index.html` directly.** It is fully regenerated by `compile_page.py`. All content changes go in `content/`.
2. **After any change to `content/`**, run `python compile_page.py content/template.html` to regenerate `index.html`.
3. **Images** go in `fig/` and are referenced as `fig/filename.ext` in content files.
4. **Do not add curly braces** (single `{` or `}`) to `content/template.html` unless they are Python format placeholders or doubled (`{{`/`}}`) to escape CSS rules.
5. **Structured blocks must be closed.** Every `:::paper`, `:::job`, or `:::tech` opening must have a matching `:::` closing fence.
